# 发现片源：自动规范命名

CloudReel 0.3.20 的保存弹窗默认启用“自动规范命名，便于匹配影片资料”。用户选择文件或文件夹后，可展开命名预览，再保存到自己的百度网盘。

## 保存效果

| 内容 | 示例 |
| --- | --- |
| 电影 | `星际穿越 (2014) - 2160p.mkv` |
| 剧集 | `硅谷 - S04E03 - 1080p WEB-DL.mkv` |
| 关联字幕 | `硅谷 - S04E03 - 1080p WEB-DL.chs.ass` |

开启后会在选定位置新建独立的作品文件夹，转存完成后只重命名本次副本，然后入库。扩展名保留原样；能识别的分辨率、来源格式、编码、动态范围等版本信息保留。相同目标名称会分配版本后缀，已有文件不会被覆盖。

可以关闭自动命名，继续按原有名称转存。剧集没有季数标记时，可在弹窗调整默认季数；已有明确季数的文件保持原季数，和网站作品季数冲突的文件保留原名。

## 识别与刮削

- 作品信息由后端从 SeedHub 详情读取，包括片名、原名、首播或上映年份、季数；不接受界面传入任意文件名或作品身份。
- 已配置 TMDB 时，先匹配明确、唯一的作品结果。命名采用匹配后的片名，入库沿用相同 TMDB 身份，自动获取影片与分集资料，不再依靠原始乱码文件名重新搜索。
- 没有明确 TMDB 匹配时，采用网站作品名和可确认的季集信息入库，交由既有自动刮削处理。设置中的“自动获取影片资料”仍控制后台资料获取。
- 支持 `S04E03`、`4x03`、`EP03`、`第三集`、纯数字及方括号集数等；不按列表顺序猜测集数。
- 无法确认季集、多集合并、季数冲突、合集、预告与花絮保留原名。电影目录中存在多个无法归属当前作品的视频时，保留原名。字幕只跟随同目录、同原始文件名前缀的视频。

## 失败与恢复

保存任务分别记录转存、规范命名和入库状态。命名失败不撤销已成功保存的文件，结果会提示未完成数量；“检查状态”重用已确认的副本 ID，继续命名或入库，不重新提交转存。

目标文件身份不明、文件发生移动或变化时停止该文件的处理。任务记录只保留必要的文件身份和命名计划，不保存分享地址、提取码、Cookie、访问令牌或媒体 URL。正式片库、观看记录和手动匹配不参与本次批量重命名。
