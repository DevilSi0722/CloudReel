# 挂载文件管理 · 0.3.21

## 调研与取舍

调研于 2026-10-30 查阅以下官方说明：

- [Apple Finder · 重命名文件](https://support.apple.com/en-qa/guide/mac-help/mchlp1144/mac)：先选择文件，再使用替换文字、添加文字或命名格式。CloudReel 保留常用文字操作，格式命名改用已匹配的影视身份，不根据列表顺序编造集数。
- [Microsoft PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)：执行前对照原名与新名。CloudReel 采用逐文件预览并检查目标冲突，不引入正则表达式、扩展名修改等专业选项。
- [Google Drive · 删除文件](https://support.google.com/drive/answer/2375102)：明确云端删除的影响。CloudReel 单独使用“从百度网盘删除”及标明数量的确认按钮，区别于原有取消挂载与从片库移除。
- [百度智能云 · 网盘接口示例](https://cloud.baidu.com/ask/179)：文件管理采用 POST、同步请求和不覆盖冲突的策略。实际网页登录行为另外通过生产会话验证。

入口收在“百度网盘 → 已挂载文件夹 → 管理文件”。不新增侧栏栏目，不在海报、详情、设置等位置重复堆叠文件按钮。先浏览目录，选择后才展示重命名与删除操作；只在确认弹窗中展开规则和预览。沿用深色面板、现有字体与按钮、系统下拉、原位动效和减少动态效果设置。

## 用户流程

1. 在挂载卡片点击“管理文件”，仅按需读取当前目录，打开子文件夹继续浏览。
2. 勾选视频或字幕，支持全选当前已显示的文件及 Shift 范围选择。每次最多选择 500 个文件；目录与其他文件不可删除或重命名。
3. 重命名支持“按影片资料规范命名”“替换文字”“添加前缀 / 后缀”。只修改文件名主体，扩展名保留；前后缀不自动加入空格。
4. 点击预览后逐项核对。“按影片资料”要求已有匹配身份，剧集要求明确季集；缺少信息、非法名称、超长名称、多个文件同目标名或目标已存在的条目跳过。不会自动覆盖、分配新集号或更改影片身份。
5. 默认关联同目录且名称前缀与所选视频完整主体一致的字幕。存在多个候选视频时不自动关联。字幕继承视频新主体并保留语言与 forced 等标记。
6. 删除预览清楚列出所有将删除的视频和字幕。确认会调用百度云端删除接口，可在百度网盘回收站查看；本机影片资料与观看记录保留，已删除片源不可用。
7. 确认后显示任务进度，禁止关闭正在执行的弹窗，可停止后续操作（完成当前视频及其关联字幕，保留已完成结果），逐项报告成功、跳过及需核对的文件；结果可从文件列表再次查看。在同一进程切换页面后可重新查看最近结果。

## 数据与并发

- 渲染进程仅提交挂载 ID、目录 ID、文件 ID 以及规则。预览完全来自后端重新读取的目录，不信任客户端提供的路径、新文件名或影片资料。
- 预览缓存最多 8 个、有效期 10 分钟，绑定账号与挂载路径；执行一次即消耗。断网后不自动重发写请求。
- 写入前按稳定 fs_id 重新核对路径、大小、可用 MD5、文件类型以及当前目录仍属于挂载。写入使用 `ondup=fail`，不覆盖同名文件。
- 重命名后按 fs_id 读回目标名称。丢失确认时只读核对新路径，核对成功更新片库，不再次写入；无法确认则显示需核对。
- 删除只接受同步成功响应，逐文件失败或异步任务回执不作为已删除依据。网络失败不会把条目误标为成功删除。
- 播放、扫描及转存期间禁止提交；提交期间暂停扫描、媒体探测及资料抓取，并阻止播放启动、账号变更、挂载移除或另一次文件操作。观看同步的身份与任务不变。
- 成功重命名只更新本机路径与文件名；成功删除只标记片源不可用，并更新挂载视频数量。资料、手动匹配、收藏、进度及待同步任务保留。刷新目录可同步已读到的最新路径，恢复网络不触发写入重试。
- 不递归删除目录，不提供彻底删除、清空回收站或自动顺序编号；恢复已删除文件使用百度网盘回收站。
