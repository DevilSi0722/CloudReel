# 播放预览、章节与片头片尾

## 使用

- 悬停或拖动进度条，在上方预览目标附近的真实画面。拖动期间不改变播放位置，松开后才跳转。
- 播放器右侧的章节图标打开“章节与片头片尾”。章节来自文件内嵌信息；没有章节的文件不会凭空生成章节。
- 在片头结束或片尾开始处点击书签，选择仅此集／影片、本季或整部剧。单集设置优先于本季，本季优先于整部剧；单集覆盖绑定实际文件，便于适配不同剪辑版本。
- 减号在所选范围禁用对应标记；重置图标清除所选范围的覆盖，恢复继承上级设置。
- 本季和整部剧的片尾按“距离结束还有多久”复用，适配不同单集时长。
- “设置 → 播放偏好 → 跳过片头”可选择按钮提示、自动跳过或关闭提示。自动片头每次播放只处理一次，避免主动回看时被反复跳过；片尾始终由用户点击跳过。

## 预览实现与边界

预览使用单独的隐藏 mpv，通过生产网盘会话及媒体中继读取原文件。它不控制正在播放的 mpv，也不更新观看进度或 Trakt。请求按 5 秒分桶，解码器优先定位附近关键帧，避免解码整段 GOP；图片显示真实解码时间，并保留文件比例，HDR 图片经过 SDR 色调映射。

未缓冲位置也能请求预览，但首次生成需要网络读取和解码，速度取决于片源索引、码率、编码及网络。优先保障主播放：主视频正在缓冲或跳转时，暂停新的取帧请求。失败时仍可查看时间和正常拖动。

主播放稳定且至少缓冲 20 秒后，后台渐进准备 16 个整片采样点，并在鼠标预览后优先准备相邻样本；每次播放最多处理 32 个后台任务。前台请求优先，可中断后台解码。主播放缓冲或跳转时停止新预取，不会一次性下载整部影片。

预览首先查询本地缓存；已有附近样本时立即显示，带 `≈` 标记的时间表示附近真实画面，随后按目标位置更新，不会把附近画面标成精确画面。前端保留最近 80 张图，服务端内存缓存上限 16 MB／96 张。磁盘图片缓存位于用户数据目录的 `thumbnails/`，按文件身份、大小和修改时间区分，采用 256 MB 配额及访问时间清理；配额维护在后台节流执行。切集、退出播放、空闲时清理取帧进程及临时输出。

## 开发验证

本批功能随 0.3.18 发布。开发与验收使用以下命令：

```powershell
npm run check
npm run verify:playback
```

真实片源测试使用隔离的百度会话副本和内存片库，始终隐藏窗口，不读取／写入 Trakt 授权，不修改正式片库或进度。正在运行的云映可能独占 Cookie 数据库；复制被锁定时需由用户方便时退出云映，测试脚本不会关闭正式应用。

验收覆盖 SDR 电影和剧集、HDR10、杜比视界，检查未缓冲位置取帧、图片缓存、独立取帧跳转、控件悬停／拖动、章节菜单跳转、片头标记和手动／自动跳过、片尾跳过，以及正常前后跳转。测试结束删除临时会话副本。可选 `CLOUDREEL_UI_OUTPUT` 只导出界面和预览图，不输出凭据或媒体地址；私人截图目录应保持在 Git 忽略范围内。
