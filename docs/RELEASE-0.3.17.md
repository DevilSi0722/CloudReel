# CloudReel 0.3.17

本次更新带来播放缓冲可视化、更清晰的设置页，以及统一的下拉菜单样式。

## 新增与优化

- **进度条缓冲显示**：区分已播放、已缓冲和未缓冲部分；拖动后保留不同位置的真实缓存区间，切换片源时清除旧状态。
- **设置页重新设计**：采用渐进式披露，默认展示账号连接与常用开关；播放偏好、影片资料、影视目录和高级设置按需展开，字幕样式与 TMDB 连接进一步分层。常用开关即时保存，各分区独立保存。
- **下拉菜单美化**：统一为深色圆角浮层，增加悬停反馈和选中标记，支持长名称换行、滚动以及原生键盘操作。

## 问题修复

- 修复设置分区展开时分类图标倒转的问题；仅旋转当前分区的展开箭头，嵌套选项的箭头独立响应。
- 修复视频画面在界面首次绘制后可能被遮挡的问题。

## 验证

- 完整构建和 117 项自动化测试通过，无跳过项。
- 使用真实百度网盘电影与剧集，通过正式媒体中继和播放器验证播放、前后跳转、缓冲显示及下拉控件。
- 便携版归档完整性及包内设置界面检查通过，覆盖图标方向、嵌套箭头、设置保存和键盘操作。

真实片源验证保持所有窗口隐藏，关闭 Trakt 写入，只读正式片库；临时会话副本在结束后删除。

## 下载

Windows 10／11 x64 便携版：`CloudReel-0.3.17-win-x64.exe`。内含所需运行库，无需安装 Node.js。
