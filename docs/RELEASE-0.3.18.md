# CloudReel 0.3.18

本次更新带来进度条画面预览、章节与片头片尾管理，并进一步打磨片库的排版和动效。

## 新增功能

- **进度条缩略图**：鼠标悬停或沿进度条移动即可查看目标附近的真实画面，拖动时也可预览。未缓冲的位置同样可以请求取帧；后台渐进预取和本地缓存加快再次查看，优先保障主视频播放。
- **章节导航**：读取片源内嵌章节，在播放器内查看并直接跳转。
- **片头片尾标记**：支持对当前影片／单集、本季或整部剧设置标记，提供片头手动提示、自动跳过及关闭提示选项；片尾支持手动跳过。单集可单独覆盖，适配不同剪辑版本。
- **海报立体反馈**：参考 Apple TV 的卡片视差，海报随鼠标位置轻微倾斜，搭配图像视差与柔光；片名和点击区域保持稳定。

## 体验优化

- 优化小字号、文字层级与间距，适配不同窗口尺寸和 Windows 显示缩放。
- 重新整理按钮、页面、菜单与对话框动效，减少标题和控件抖动，并响应系统“减少动态效果”偏好。
- 首页精选简介按可用空间显示完整行，超出时使用省略号，避免半行截断；为标题、操作按钮和轮播导航预留空间。
- 精选及影片详情预留风格化标题图空间，减少图片加载时的布局跳动。标题图按 TMDB 接口语言标签选择；通用 `zh` 标签仍可能包含繁体字形。

## 使用说明

缩略图首次加载仍取决于网盘网络、片源索引与编码；缓存命中后可更快显示。章节来自文件自身，片头片尾由用户设置。本版暂未加入在线字幕搜索。

## 验证

- 完整构建和 125 项自动化测试通过，无跳过项；界面回归覆盖 7 组窗口尺寸与显示缩放组合。
- 打包资源的真实百度网盘验收通过，覆盖 SDR 电影、SDR 剧集、HDR10 与杜比视界片源，以及前后跳转、未缓冲位置取帧、悬停／拖动预览、章节与片头片尾操作。
- 本次真实片源测试中，首次预览取帧约 2.2–3.2 秒，缓存命中约 0–1 毫秒；这些是本机测试结果，不代表所有网络与片源的速度。
- 包内设置页回归、版本信息、源码与前端资源一致性、播放器运行库及便携版归档完整性检查通过。

所有验收窗口始终隐藏，使用隔离会话和内存片库，Trakt 写入为零，测试结束后删除临时会话副本。
