# CloudReel 0.3.20

选择网盘文件夹即可挂载到片库，文件改名后也能继续播放。

- **文件夹挂载**：百度网盘页面集中展示已挂载文件夹。点击“挂载文件夹”后逐层选择，只读取当前打开的目录；确认后自动整理所选文件夹及子目录中的视频。
- **挂载管理**：支持刷新、取消挂载，并与设置页共用目录列表。已有扫描目录继续保留；取消挂载保留已入库影片与观看记录。
- **改名后直接播放**：按稳定文件 ID 获取当前原文件地址，自动修正本地路径。文件改名或移动后无需手动重新扫描，保留影片资料、匹配信息与观看记录。
- **目录身份**：新挂载文件夹记录网盘 ID，刷新时可跟随文件夹改名或移动。真正删除或无法访问的文件会给出明确提示。
- **静默刷新**：每次启动自动检查已挂载目录；“自动刷新片库”开关仅控制之后每 15 分钟的检查。后台扫描及后续海报、资料获取不显示进度条或旋转提示，新增和变更自动合并到片库。
- **手动刷新入口**：左下角新增“刷新片库”，显示扫描进度并支持停止，保留当前页面和已打开的影片。后台已有刷新时直接显示当前任务，避免重复扫描；首次挂载仍显示读取进度。
- **观看同步归位**：Trakt 的读取进度、自动同步、重试、最近活动和断开操作移至“设置 → 观看同步”，默认折叠，账号区域可直接进入管理。

Windows x64 便携版：`CloudReel-0.3.20-win-x64.exe`。

## 本地验证

- TypeScript 与前端构建通过，140 项自动化测试通过，无跳过项；覆盖刷新调度、后台转手动、取消、资料任务衔接和设置中的同步操作。
- 包内隐藏界面验证通过：按需加载目录、分页、错误重试、快速切换目录与重复挂载。
- 包内真实百度网盘专项验收通过：只扫描所选目录，挂载目录旧路径恢复；使用失效路径配合真实文件 ID 验证 SDR 与杜比视界片源的原文件播放、缓存与跳转，全程无需重新扫描。
- 使用隔离会话、内存片库和隐藏窗口，未写入用户片库、进度或 Trakt；临时会话在验证后删除。
- 验证限制：额外的电影连续播放、缩略图与章节综合回归多次因缓冲或测试跳到片尾中断，本次未将其计为完整通过。
