# CloudReel 0.3.20｜发现片源，保存即入库

本次更新将 SeedHub 片源发现、百度网盘保存和片库整理连接起来。在 CloudReel 中找到想看的电影或剧集，选择资源并保存，即可规范命名、加入片库并自动获取影片资料。

## 新增与优化

- **原生片源发现**：集成 SeedHub，支持电影、剧集、动漫浏览、搜索及作品详情。默认展示“近期热门”，滚动到底部自动加载更多。
- **网盘来源筛选**：资源直接显示百度、夸克、阿里、迅雷等来源与数量，支持按来源筛选；有百度资源时默认展示百度。
- **选择后保存**：预览分享内容，按需选择单集、多个文件或整个文件夹，保存至自己的百度网盘目录，完成后自动加入片库。
- **自动规范命名**：默认按 `片名 (年份)`、`剧名 - S04E03` 整理本次保存的副本，保留扩展名、画质信息和关联字幕。支持命名预览、调整默认季数及关闭自动命名；无法确认的季集、合集和花絮保留原名，已有文件不会被覆盖。
- **元数据自动关联**：明确匹配 TMDB 后，入库直接沿用作品身份，配合“自动获取影片资料”补全海报、简介与分集信息，减少对原始文件名的依赖。
- **按文件夹挂载**：逐层浏览并选择需要的网盘目录，首次挂载自动读取。支持刷新与取消挂载，取消挂载时保留已入库影片及观看记录。
- **静默刷新片库**：每次启动自动在后台检查挂载目录；开启“自动刷新片库”后，每 15 分钟继续检查。左下角新增“刷新片库”入口，可手动显示刷新进度；观看同步操作统一移入设置页。

## 播放修复

- 修复网盘文件改名或移动后无法播放的问题，按稳定文件 ID 恢复当前路径，无需重新扫描，保留原有影片资料和观看进度。
- 修复部分影片开始播放时出现 `HTTP 403／百度 31362` 的问题。遇到不可用的签名地址时，自动核对文件身份并切换原文件取址方式，支持原文件播放、缓存和跳转。

## 下载与升级

Windows x64 便携版：`CloudReel-0.3.20-win-x64.exe`。退出旧版后启动新版即可，正式版继续使用原有账号、挂载目录、片库和观看进度。
