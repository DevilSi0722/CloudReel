# CloudReel 0.3.21｜在影院里，整理你的网盘

现在可以直接在 CloudReel 中管理已挂载的百度网盘影视文件，并随时查看网盘容量。

## 网盘空间，一眼可见

- 百度网盘账号卡片内显示简洁容量条、已用／总容量与剩余空间。
- 登录后自动读取，每分钟静默更新；支持手动刷新，文件整理或片源转存后也会重新核对。
- 空间达到 90% 时提示；网络异常保留上次读数，避免将读取失败显示为空网盘。

## 批量整理视频与字幕

- 从“百度网盘 → 已挂载文件夹 → 管理文件”进入，按目录浏览、筛选并多选视频或字幕。
- 按已匹配的影片资料规范命名，电影采用“片名 (年份)”，剧集采用“剧名 - S01E01”，保留画质信息。
- 支持批量替换文字、添加前后缀，扩展名保留，同名字幕可随视频一起处理。
- 应用前对照原名与新名；无法确认季集、名称不合法或存在同名冲突时跳过，避免覆盖其他文件。

## 云端删除，清楚确认

- 批量删除前列出全部目标，并明确提示会删除百度网盘中的原文件，可前往网盘回收站查看。
- 本机保留影片资料、收藏和观看记录，已删除片源标记为不可用。
- 文件操作显示进度及逐项结果；部分失败时保留成功结果，并提示需核对的文件。

## 片库跟随文件更新

- 重命名后立即更新片库路径，无需重新扫描即可继续播放。
- 执行前重新核对文件 ID 与挂载位置，避免操作已移动或变更的文件。
- 网络中断时核对结果，避免自动重复执行；播放、扫描及转存期间会等待完成后再处理文件。

沿用 CloudReel 的深色界面与渐进式披露，不增加侧栏栏目。现有账号、片库与观看进度继续使用。
