# CloudReel 0.3.22｜安装版自动更新与网盘整理优化

## 标准安装版，后续更新更方便

- 正式发行改为 Windows 安装版，支持选择安装位置，沿用旧版片库、账号登录及观看记录。
- 设置页新增软件更新：启动后静默检查并在后台下载，支持查看更新内容和下载进度。
- 下载完成后可选择“重启并更新”；播放或文件处理期间会等待，普通退出不会自动安装。
- 下载失败可重试，安装包校验不通过时不会安装。

旧便携版用户需要先手动安装本版一次；后续更高正式版本发布后即可使用软件内更新。

## 片源保存，自动命名更准确

- 改进带画质后缀的剧集识别，兼容 `01 4K`、`05-4K`、`09~4K`、中文片名加集数、全角字符等常见命名，保留画质与扩展名。
- 结合文件名、季目录及作品信息核对季集；冲突、多集合并、上下分段等无法确认的文件保留原名，并显示具体原因。
- 同集多版本及字幕在预览中显示对应的新名称，避免保存后才发现同名调整。
- 命名预览支持查看整批文件、按需加载更多，并筛选保留原名的项目，不再只展示前几个文件。

## 一次选择，删除整个文件夹

- 网盘文件管理支持勾选文件夹，并与视频、字幕混合批量删除。
- 点击文件夹名称仍可进入目录，勾选用于选择；沿用现有操作栏，无需逐个选择剧集文件。
- 删除前预览所选项目，文件夹明确标注“包含全部内容”。确认后删除文件夹、子文件夹及其中的其他文件，可前往百度网盘回收站查看。

## 修复已删除版本仍出现在片库的问题

- 修复网盘刷新已确认文件缺失，但首页海报、分集与播放版本列表仍保留旧条目的问题。
- 在应用内删除文件或文件夹后，立即同步隐藏对应片源；保留的其他版本继续正常显示与播放。
- 当前所选版本被删除时，如同一集还有其他版本，详情页会切换到可用版本并保持当前选集。
- 本机影片资料、收藏与观看记录保留；从网盘恢复文件后，刷新可重新显示对应片源。

网络异常或刷新中断仍会保留现有片库，避免将暂时无法读取误判为文件已删除。
