# CloudReel 0.3.23｜浏览与播放体验优化

- 发现页从影片详情返回时，回到进入前的浏览位置，保留已加载的影片与筛选条件，方便接着挑选片源。
- 修复右方向键偶发锁定倍速的问题：短按前进 5 秒，长按临时 3 倍速，松开恢复原速；漏收松开事件或失去焦点时也能结束临时倍速。
- 继续观看的“隐藏”调整为“从继续观看中移除”，移除后不再显示“已隐藏”计数、管理列表或恢复入口。
- 发现页移除保存记录展示，当前保存结果仍在原弹窗中反馈。
- 修复关闭主窗口后，发现页隐藏窗口仍让应用留在后台的问题。退出时先保存本地进度及待同步记录，清理播放器和会话，避免网络任务延迟退出。

安装包：`CloudReel-Setup-0.3.23-win-x64.exe`。软件内更新沿用安装版更新机制。
