# SeedHub 原生集成测试版（2026-10-29）

分支：`codex/seedhub-integration-prototype`。版本：`0.3.20`。未提交、未推送 GitHub；保留工作区已有的 0.3.20 修改。

## 试用

便携包：`release/seedhub-test/CloudReel-0.3.20-SeedHub-Test-win-x64.exe`。

1. 启动测试版，在“百度网盘”中完成网页登录。
2. 进入左侧“发现”，浏览分类或使用顶部搜索框搜索片名。
3. 打开作品和资源，检查分享内容，可选单集、多个文件或整个文件夹。
4. 选择自己的影视文件夹，点击“保存并加入片库”。完成后只读取目标目录并添加新视频。
5. “持续挂载此目录”默认勾选，后续刷新会跟踪该目录；取消勾选仍会将本次保存目标中的新增视频加入片库。

保存位置要求为根目录下的文件夹，避免一次保存触发全盘入库。测试版使用独立的 `%APPDATA%/CloudReel-SeedHub-Test`，首次需登录；正式版片库、账号及观看进度不会自动迁入。浏览、保存和播放均不需要连接 Trakt。

## 实现

- 原生发现页包含电影、剧集、动漫、排序、搜索、分页、作品简介和按需展开的资源列表，采用现有暗色界面和动效规范。
- 网站在无 Node、无 preload 的沙盒隐藏浏览器中读取，限定主导航来源，拒绝权限、下载与弹窗。网站与百度使用不同会话。
- 从中转页二维码识别实际网盘，目前只支持百度保存。失效分享、提取码错误、安全验证和其他网盘有明确提示；用户点击后可打开官方页面自行验证。
- 分享 API 保留 int64 文件 ID，按需读取目录和分页。打开已选文件夹会取消整目录选择，避免只想选单集却保存整季。
- 目标目录 ID 在写入前重新解析；重名保留副本。重复请求复用任务，未知结果不会自动重新提交。
- 百度同步响应可能返回 `task_id: 0`，此时根据同步文件记录确认完成；只有非零编号才查询异步任务。测试覆盖这一真实响应形态。
- 保存与入库期间阻止切换账号，提交和入库前再次核对身份。入库失败显示“已保存”，不会误报网盘保存失败。
- 任务记录不保存分享 URL、提取码、Cookie、令牌或媒体地址。发现列表缓存五分钟，手动刷新绕过缓存；实际海报域名加入图片 CSP。

## 复现命令

```powershell
npm run build
node --test --test-concurrency=1 tests/*.test.mjs
# 真实网站与匿名分享 API，只读、隐藏窗口
npm run verify:seedhub -- --share-api
# 复用已保存测试文件，不新增网盘文件
npm run verify:playback -- --discovery --reuse
# 独立便携包
npm run dist:seedhub
# 从测试包运行隐藏 UI 和真实播放验收
$env:CLOUDREEL_PACKAGE_ROOT = Join-Path (Get-Location) 'release/seedhub-test/win-unpacked/resources/app.asar'
node --test tests/discovery-ui.test.mjs
$env:CLOUDREEL_VERIFY_PACKAGE_ROOT = $env:CLOUDREEL_PACKAGE_ROOT
npm run verify:playback -- --discovery --reuse
```

播放检查只复制本应用自身的百度会话。正式应用锁住会话文件时需先由用户退出。未带 `--reuse` 的转存验收会尝试向指定测试目录保存文件，必须先获得用户对该目录写入的授权。

默认并发运行既有 UI 测试曾出现时序失败；本次使用全量串行回归。隐藏 UI 覆盖搜索旧响应丢弃、渐进资源、单集选择、独立目录、单次提交、根目录限制、刷新及 980×720 下保存按钮可见。

## 代码入口

- `src/Discovery.tsx`、`src/discovery.css`：原生发现和保存流程。
- `electron/core/discovery.mjs`、`electron/services/discovery*.mjs`：页面归纳、沙盒浏览、串行与缓存。
- `electron/services/baidu-share.mjs`：分享读取、转存、去重和账号保护。
- `electron/services/scanner.mjs`：仅添加新视频的定向入库。
- `experiments/seedhub/`、`scripts/verify-seedhub.mjs`：有限样本只读联网检查。
- `tests/discovery-*.test.mjs`、`tests/fixtures/real-baidu-discovery.mjs`：任务、隐藏 UI 和真实链路检查。

`jsqr@1.4.0` 是运行依赖，在内存解码二维码；测试包包含该依赖和原生播放器。
