# CloudReel 0.3.20 · SeedHub 测试版

打开 `CloudReel-0.3.20-SeedHub-Test-win-x64.exe` 即可运行，无需安装。

测试版使用独立数据目录，首次请在“百度网盘”中登录；正式版已有片库与观看进度不会迁入。

本次验收在授权的 `/CloudReel-SeedHub-Test` 中保留了一份约 1.2 GB 视频。登录后可直接挂载这个目录试播，也可从发现页选择其他资源。

## 保存影片

1. 点击左侧“发现”，浏览分类或在顶部搜索片名。
2. 打开作品，点击一个资源，等待分享文件显示。
3. 选择文件或文件夹。如只想保存一集，打开季目录后只勾选该集。
4. 点击“选择文件夹”，打开自己网盘中的影视目录，确认位置。
5. 点击“保存并加入片库”，在“保存记录”查看结果；完成后到电影或剧集页播放。

默认持续挂载保存目录，之后按片库刷新设置发现变化。取消勾选仍会入库本次目标中的新增视频。重名文件保留副本。

目前仅支持百度网盘和网页登录。失效资源可换其他版本；网站或百度要求验证时，点击相应的官方页面按钮完成验证后重试。结果待确认时，先检查网盘文件，避免重复保存。

试用反馈请注明片名、失败操作和界面错误文字，不需要提供登录凭据或完整媒体地址。
