# 界面动效

网盘容量融入现有账号卡片，使用一条细进度条、已用／总量及一行辅助信息。更新时间弱化，刷新图标保留标准点击范围；每分钟自动更新只替换数据，不移动下方目录或展示全局忙碌提示。容量达到 90% 时才出现暖色提示；读取失败保留上次读数并在原位置标记，未知容量不显示为零。

挂载文件管理入口收在挂载卡片内。文件列表选择前仅显示筛选与全选，选择后在同一操作条显示重命名和删除；重命名规则和逐项预览只在弹窗内展示。危险操作使用明确云端目标与数量的确认按钮，执行时显示进度和结果，不添加侧栏导航或重复的海报工具栏。文件行选中只改变底色，不缩放内容，窗口尺寸变化保持操作按钮可见。

动效以稳定的文字和操作区域为基础。参考 [Apple Human Interface Guidelines · Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 中简短、准确、有目的的反馈原则，减少高频操作中的多余运动。

| 场景 | 表现 | 保持稳定的部分 |
| --- | --- | --- |
| 按钮与导航 | 100–140 ms 明暗、颜色反馈 | 文字、图标与点击范围，不整体缩放 |
| 海报、继续观看、分集剧照 | 图片在裁剪框内轻微放大，封面边缘与阴影响应 | 卡片框、标题、播放按钮和观看标记 |
| 精选轮播 | 650 ms 交叉淡化，背景在 8 秒内轻微推进 | 标题和操作区域不随背景缩放 |
| 页面切换 | 新内容在最终布局短暂淡入，180 ms | 不插值页面尺寸，不位移文字，不截图拉伸长短页面 |
| 菜单与对话框 | 菜单 120 ms 原位显现；对话框 220 ms 淡入 | 最终锚点、文字尺寸与布局 |
| 播放器 | 控件原位淡出淡入；预览不随换帧重复闪烁 | 原生视频区域、菜单坐标与交互区域 |
| 设置展开 | 内容在最终高度显现，仅箭头旋转 | 不连续插值高度并推动相邻文字 |

快速切页取消上一次淡入；后台状态更新不触发页面动画。系统启用“减少动态效果”时关闭 CSS 动效和页面淡入。

首次挂载与手动刷新显示整理进度，保留当前页面。启动及定时刷新全程静默，包括扫描后的海报和资料获取；左下角“刷新片库”可将正在进行的后台任务转为可见进度，复用任务。观看同步收在设置的折叠分区，账号区域“管理同步”展开并定位该分区，标题避开固定顶部栏。

片库竖版海报另参考 [Apple 的 tvOS 焦点与视差设计](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection)。视觉卡面随鼠标位置倾斜，边缘最大约 4°，内部图像视差最大 2 px，叠加随指针移动的低强度柔光。点击区域和卡片下方的片名不参与变换；离开、滚动、失去窗口焦点或启用“减少动态效果”时复位。仅当前悬停卡片按帧更新，不反复刷新 React 片库；触屏不启用此效果。

精选区域按自身尺寸排版，为标题、按钮、导航预留空间。简介根据实际可用高度显示 1–4 行完整文字，溢出使用省略号；空间不足以显示一行时隐藏简介。保留完整简介数据，不再提前截取固定字数。长文字标题最多两行，风格化标题图保持比例缩放。

TMDB 风格化标题图仅按接口语言标签选择，不使用 OCR。通用 `zh` 标签不能保证图片中的字形为简体。精选与 TMDB 详情页预留标题图高度，减少异步图片加载造成的排版跳动。

从普通片库或精选进入剧集详情时，选中最早正片季的第一集（只有特别篇时选中首个特别篇）；从“继续观看”的封面或标题进入时，选中卡片所对应的续播集及季。卡片中央的播放按钮仍直接续播。切季选中该季首集。点击剧照、集名或卡片切换选择，上方的媒体信息、播放按钮及版本选择跟随所选集，不立即播放。选中状态只改变边框与文字明暗，不移动卡片；后台观看进度与资料更新不会抢走当前选择。单集观看操作保留在右键菜单，修正识别与匹配等低频操作收进上方更多菜单。

顶部作品简介和分集简介均保留两行空间，仅在确实溢出时显示“更多”。完整简介在紧凑的对话框中阅读，长内容在框内滚动；点击空白处、关闭按钮或按 Escape 关闭。弹窗不改变详情卡片或分集的尺寸、位置，不触发播放或切换所选集，关闭后焦点回到原按钮。

详情页自动化回归覆盖选集、切季、多版本、不可用文件、资料更新、不同分辨率下的两行简介与弹窗、续播详情入口及电影播放入口。真实网盘验证可运行 `npm run verify:playback -- --details`，通过隔离会话、生产媒体探测与播放器确认普通入口及续播入口所选集的信息和实际播放文件一致。

验证使用隐藏 Electron 窗口，检查悬停、按下、快速切页、菜单锚点、标题图延迟到达及减少动态效果。播放器的变动另通过真实百度网盘会话副本、生产媒体转发及播放器验证，不写入真实片库、进度或 Trakt。
